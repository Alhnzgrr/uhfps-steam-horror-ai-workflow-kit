# Build Feature Command

## Purpose

Run a UHFPS + Zenject Steam horror feature through design, implementation,
setup, review, and validation.

## Default Flow

1. UHFPS Architect
2. UHFPS Gameplay Programmer
3. UHFPS Setup Specialist
4. Save Load Reviewer when persistent state changes
5. Code Reviewer
6. Horror Design Reviewer when player experience is affected
7. Validate

## Required Output

- phase list
- required agents
- required rules and skills
- required setup
- review gates
- next immediate action

## Rules

- Do not claim all phases are complete if only planning has been done.
- Route back to implementation when must-fix issues remain.
- Treat missing setup as incomplete work.
