# Review Code Command

## Purpose

Review implemented code for UHFPS compatibility, Zenject integration, runtime
reference safety, save/load impact, and Steam horror quality.

## Required Inputs

- changed files or code
- intended behavior
- UHFPS systems involved
- setup notes
- save/load requirements

## Output Shape

```text
Must Fix:

Should Improve:

Optional:

Save/Load Gaps:

Setup Gaps:

Validation:
```

## Rules

- Findings come first.
- Prioritize correctness, UHFPS safety, and hidden setup problems over style.
- If no findings exist, state that clearly.
