# Architect Command

## Purpose

Create a technical plan for a UHFPS + Zenject Steam horror feature before
implementation.

## Required Inputs

- feature description
- intended player experience
- involved UHFPS systems if known
- persistence requirements if known
- scene/prefab/asset constraints

## Required Output

- UHFPS systems used
- new scripts and responsibilities
- Zenject services
- Inspector references
- save/load impact
- setup requirements
- horror design risks
- validation plan

## Rules

- Do not write implementation code unless explicitly requested.
- Do not rewrite UHFPS core systems.
- Do not skip setup and save/load analysis.
